ADMIN MODULE · PHASE 1

Admin setup is next.

Admin accounts are not created by the login form. To explicitly create the first demo Admin, open the browser console on the LearnSpace home page and run:
window.provisionLearnSpaceAdmin("admin@example.edu", "LearnSpace Admin")

This demo setup only appends a new Admin account. If the email already belongs to another role, setup is refused. Demo login and role navigation do not verify credentials and are not secure.
